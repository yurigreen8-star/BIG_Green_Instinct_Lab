# BIG_Green Instinct Lab

Исследовательский проект: может ли адаптивное коллективное поведение возникнуть
из взаимодействия независимых специализированных вычислительных механизмов
(«искусственных инстинктов»)?

Мы не строим единый оптимизатор. Мы строим минимальные механизмы с собственными
внутренними состояниями и измеряем, что возникает между ними.

**Статус:** v3.0 (среда E0). Инфраструктура и математика проверены.
Главная гипотеза (H-D: взаимодействие даёт результат, не сводимый к расписанию)
НЕ подтверждена и НЕ опровергнута — не хватает контрольных расписаний.
Ниже перечислены и положительные, и отрицательные результаты.

## Среда E0

- 30 участков, `q_i ~ N(0,1)` независимые, априор `N(0,1)`
- Зонды: fast (c=1, s²=1.0), standard (c=3, s²=0.25), precise (c=8, s²=0.04);
  повторы разрешены
- Наблюдения детерминированы ключом `(episode_seed, parcel_id, probe_type_id,
  rep_index)` — common random numbers, порядок зондирования не влияет на чтение
- Байесовское сопряжённое обновление по точностям
- Режим A: бюджет 30. Режим B: бюджет 1000, стоп по `UCB95(EVPI) <= 0.05`
- Полезность: выбор одного участка; `regret = q_best - q_chosen`

## Архитектура v3.0

| Модуль | Компетенция | Чего НЕ видит |
|---|---|---|
| `Curiosity` | interest = EMA(ignorance · novelty), обновление всех объектов | бюджет, цены, EVSI, mu |
| `CuriosityIG` | то же с нормированным IG (изолированная альтернатива) | то же |
| `Ratio` | EVSI/cost + строгое доминирование предложения | состояние Curiosity |
| `Coordinator` | структурный арбитраж; верифицирует арифметику доминирования, не пересчитывает EVSI | belief, EVSI-функции |
| `runner_v3` | цикл, CRN-наблюдения, полный event log | — |

Инварианты независимости проверяются тестами (AST по импортам, сигнатуры,
поведенческие инвариантности к бюджету и ценам).

## Проверенные математические факты

1. `E[regret] = E[EVPI(b_T)]` для любого момента остановки; `R = EVPI(b_0) - G`.
2. Три агрегации остатка связаны тождеством `L3 = -k * L1`, `k = T/E`.
   Прежнее «расхождение калибровки» было ошибкой агрегации, а не математики.
3. Аналитический EVSI совпадает с независимым пересчётом до 6 знаков;
   `EVSI <= EVPI`; телескопичность `sum(dV) = V_T - V_0`.
4. Bayesian Surprise (KL posterior||prior):
   `BS = IG + a/(2(a+r)) * (z^2 - 1)`, откуда `E[BS] = IG` точно.
   Асимптотика `BS - S = z^2/4` (не `z^2/2`); `BS < S` на `(0.3966, 1.5673)`.
5. Behavioral novelty выродилась: `B = 2 * IG` точно в FAST-only E0.
6. Жадность по `EVSI/c` никогда не выбирает строго доминируемое одиночное
   действие; пакетное пространство непусто (1 precise доминирует 8×fast при
   равной цене 8; joint-оптимум порога EVPI=0.05 на 2 участках = 83 против 88
   у жадности по удельной точности).

## Основные результаты (seeds 0–99, EXPLORATORY)

budget = 30:

| Группа | regret | probes | unique |
|---|---:|---:|---:|
| CURIOSITY_SOLO | 0.5763 | 30 | 30 |
| RATIO_SOLO = B_EVSI_cost | 0.3542 | 20.89 | 15.66 |
| COMBINED | 0.3646 | 30 | 23.86 |
| B_none | 2.0854 | 0 | 0 |

- Тройное тождество `CURIOSITY_SOLO = B_IG = B_random_without_replacement`
  до 16 знаков: при одном зонде на участок порядок обхода не влияет на итог.
- COMBINED против B_EVSI_cost: delta = +0.0103, p_holm = 1.0 — не лучше.

budget = 45:

- Тождество нарушено: 0.4866 / 0.4232 / 0.5763 — состояние Любопытства стало
  причинно значимым.
- COMBINED 0.2322 против B_EVSI_cost 0.2765: численно лучше, p_holm = 0.75 —
  не значимо.
- Ratio: 8.33 верифицированных контрпредложений на эпизод из 15.19 повторов,
  ни одно не отклонено верификацией Координатора.

## Отрицательные и открытые результаты

- H-A опровергнута при budget = n: внутреннее состояние Любопытства причинно
  нерелевантно исходу (доказано конструктивно, не статистически).
- `CuriosityIG` даёт траектории, идентичные базовому Curiosity (10/10 на обоих
  бюджетах): альтернативная формула не выходит из редукции в E0.
- H-D не закрыта: отсутствуют контрольные расписания (фиксированное и случайное
  чередование) и контроли повторов («обход + случайные повторы»,
  «обход + обратный порядок»).
- Факторный контраст `I_CR` не применяется к regret (механизмы замещающие,
  не аддитивные) и вырожден для budget_used.
- Численное превосходство COMBINED при budget=45 не отделено от простого
  чередования механизмов, поэтому эмерджентностью не объявляется.
