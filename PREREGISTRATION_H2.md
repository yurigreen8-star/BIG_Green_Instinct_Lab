# Предрегистрация гипотезы H2

## 1. Формулировка гипотезы
Политика `B_EVSI_cost` обеспечивает статистически значимо более низкую медиану regret, чем политики `B_IG`, `B_mean_prec` и `B_EVSI`, при ограниченном бюджете.

## 2. Дизайн эксперимента
- **Режим**: Mode A (жесткий бюджет, без ранней остановки по EVPI).
- **Количество сценариев**: 100 (свежие, непересекающиеся с предыдущими).
- **Диапазон seed**: 100 – 199.
- **Параметры среды**: 30 участков, начальный prior N(0, 1) для каждого.
- **Бюджет**: 30 кредитов.
- **Каталог зондов**: 3 типа на участок (fast: c=1, s²=1; standard: c=3, s²=0.25; precise: c=8, s²=0.04).

## 3. Оцениваемые политики
- **Целевая**: `B_EVSI_cost` (максимизация EVSI / cost).
- **Конкуренты**: `B_IG` (IG / cost), `B_mean_prec` (жадный по mu + самый точный зонд), `B_EVSI` (абсолютный EVSI).
- **Дополнительный baseline (exploratory)**: `B_precise_diverse` (покупает максимально возможные точные зонды на *разных* участках, пока хватает бюджета).

## 4. Метрики
- **Первичная**: Regret (разница между истинным качеством выбранного участка и истинным качеством лучшего участка).
- **Вторичные**: PCS (%), средний расход бюджета, среднее число зондов.

## 5. Статистический анализ
- **Тест**: Парный критерий знаковых рангов Уилкоксона (Wilcoxon signed-rank test).
- **Сторонность**: **Двусторонняя** (`alternative='two-sided'`). Мы проверяем любое различие, но гипотеза считается подтвержденной только если медиана `B_EVSI_cost` *ниже*.
- **Поправка на множественные сравнения**: Холма-Бонферрони (Holm-Bonferroni) для семейства из 3 тестов (`B_EVSI_cost` vs `B_IG`, `B_mean_prec`, `B_EVSI`).
- **Уровень значимости**: alpha = 0.05.

## 6. Критерий успеха (Строгий)
Гипотеза H2 считается **подтвержденной** ТОЛЬКО ЕСЛИ:
1. Скорректированное p-value (Holm) < 0.05 для **всех трёх** сравнений целевой политики с конкурентами.
2. Направление эффекта соответствует ожидаемому (медиана regret у `B_EVSI_cost` строго меньше, чем у каждого из конкурентов).

Если хотя бы одно сравнение не показывает статистически значимого различия, H2 **не подтверждена**.
